# Poco

Read `README.md` first: it has the project goal, current status, file map, design rules, changes from the original spec, planned next steps and how this user likes to work.

Quick facts:
- iPad onboarding app for Poco, a robot penguin that helps autistic kids read and regulate emotions. Vite + React 18 + TS, plain CSS.
- Windows machine. Node may not be installed yet (`winget install OpenJS.NodeJS.LTS`); Python is not installed.
- Verify changes with `npm run build`. For UI changes, check the layout at 1180×820 and 1024×768.
- Talk through bigger changes with the user before writing code.
